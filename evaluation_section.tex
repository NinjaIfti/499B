\section{Evaluation}
\label{sec:evaluation}

We evaluate LectureAssist's question generator by comparing four generation
pipelines on the same source material and scoring every question with
independent ``LLM-as-judge'' models. The evaluation asks four questions:
(RQ1)~does the agentic pipeline produce better multiple-choice questions than
single-shot prompting baselines, including stronger prompting strategies
(chain-of-thought, program-of-thought)?
(RQ2)~how does each pipeline behave as the target difficulty increases?
(RQ3)~is the agent's internal self-validator a reliable quality gate, measured
against an external judge?
(RQ4)~how trustworthy is the LLM judge itself, assessed with a cross-family
judge panel and an answer-solver calibrated on known-answer questions?

\subsection{Experimental setup}
\label{sec:eval-setup}

\paragraph{Source material.} All pipelines generate from the same processed
lecture material --- a calculus chapter on limits ingested by the production
pipeline (document text, retrieval index, and generated summary), so every
pipeline sees identical grounding content.

\paragraph{Pipelines.} We compare:
\begin{itemize}
  \item \textbf{Agentic} --- the production per-question loop of
        \emph{Plan $\rightarrow$ Generate $\rightarrow$ Validate $\rightarrow$
        Retry}. A planner selects topics; each question is drafted, checked by
        a self-validator on grounding, difficulty, instruction compliance and
        uniqueness, and regenerated (with the failure reason fed back) until it
        passes or a retry budget (3 attempts) is exhausted. The validator
        chooses the remediation (\texttt{regenerate}, \texttt{fetch\_context},
        or \texttt{replan\_topic}), and the generator may issue its own
        retrieval query over the lecture index when it judges the supplied
        context insufficient.
  \item \textbf{Non-agentic} --- a single LLM call per batch that writes
        questions directly, with no planning, validation, retrieval or retry.
  \item \textbf{Chain-of-thought (CoT)} --- as non-agentic, but the prompt
        instructs the model to reason step-by-step about the content before
        writing each question.
  \item \textbf{Program-of-thought (PoT)} --- as non-agentic, but the model is
        instructed to derive each question via explicit worked
        computation before committing to the answer.
\end{itemize}

\paragraph{Coverage fairness.} The three baseline pipelines read the document
through an identical sliding window that steps across the whole chapter, one
step per batch, with a uniform batch size --- so no baseline is advantaged by
seeing more (or more varied) content, and differences between them reflect the
prompting strategy alone.

\paragraph{Scale.} For every pipeline $\times$ difficulty cell
($d\in\{\text{easy},\text{medium},\text{hard}\}$) we generate $N{=}50$ MCQs:
$4\times3\times50 = 600$ questions in total.

\paragraph{Models and infrastructure.} All four pipelines use the same
generator model (\texttt{gemma3:4b}), pinned so that no pipeline silently
escalates to a larger model; the local judge is a larger, separate model
(\texttt{gemma3:12b}) that never wrote or validated any question. Generation
runs locally via Ollama on a single 16\,GB T4. Model output is parsed with a
fail-closed JSON pipeline: malformed replies are repaired where the repair is
provably safe (e.g.\ typographic quotes used as JSON delimiters) and otherwise
discarded and regenerated --- a discarded reply can only cost time, never
inject a malformed question. A structural gate additionally rejects any MCQ
whose four options are not all non-empty or whose answer key is not one of
A--D, so every evaluated question is well-formed by construction.

\subsection{Protocol: alignment with EQGBench}
\label{sec:eval-protocol}

We adopt the evaluation frame of EQGBench
(arXiv:2508.10005),\footnote{If the surrounding document uses BibTeX, replace
this parenthetical with a proper \texttt{\textbackslash cite} entry.} which scores
generated educational MCQs with an LLM judge along five dimensions ---
correctness, clarity, difficulty match, distractor quality, and holistic
overall quality --- plus a binary accept decision. Following EQGBench we do
\emph{not} report $n$-gram overlap metrics (BLEU/ROUGE): our generation is
open-ended over a chapter rather than conditioned on reference questions, so
there is no gold question set to overlap with, and $n$-gram similarity to any
particular phrasing is not evidence of quality. Beyond the EQGBench
dimensions we retain three measures the benchmark omits --- duplicate rate,
embedding diversity, and independent answer agreement --- because (as the
pilot below shows) they carry the discriminating signal that saturated judge
scores miss.

\subsection{Per-question scoring: the judge}
\label{sec:eval-judge}

Every generated question is sent individually to the judge with the grounding
content and a strict rubric:

\begin{verbatim}
You are an impartial, strict but fair exam-quality judge. Score this ONE
MCQ question on a 1-5 scale for each dimension.

Target difficulty: [DIFF] - [difficulty description]
Content snippet (ground truth):
[lecture content]

Question:
Q: [question text]
Options: [options]
A: [answer]

Score 1 (worst) to 5 (best) on:
1. correctness        - factually correct, answerable from the content
2. clarity            - unambiguous, well-formed wording
3. difficulty_match   - actual difficulty matches the target
4. distractor_quality - wrong options plausible but clearly wrong
5. overall            - holistic quality

BE DISCRIMINATING - use the FULL range, do not default to 5:
  5 = flawless; 4 = good; 3 = ordinary; 2 = weak; 1 = poor.
Then decide accept (true) or reject (false).

Return STRICT JSON:
{"correctness":1,"clarity":1,"difficulty_match":1,
 "distractor_quality":1,"overall":1,"accept":true,"reason":""}
\end{verbatim}

The judge fails closed (a parse error yields a rejected, zero-scored verdict,
so failures cannot inflate the result), and \texttt{overall}$<3$ forces
\texttt{accept}$=$\texttt{false} for consistency.

\paragraph{Judge panel and the same-family objection.} The generator and the
local judge share the Gemma-3 family, so they may share blind spots. We
therefore re-judge the same questions with a cross-family cloud judge
(DeepSeek-R1, a different model lineage) and a second same-family-adjacent
judge (Gemini~2.5 Flash), and report inter-judge agreement. The cross-family
judge serves as the independence check for answer correctness; agreement
between judges of different lineages is evidence that scores reflect question
quality rather than family idiosyncrasy.

\paragraph{Independent answer solving and gold calibration.} Separately from
rubric scoring, a solver model answers each MCQ \emph{blind} --- it sees the
question and options but not the generator's marked answer. The
\emph{independent match} rate is the fraction of questions where the blind
solver picks the marked answer. Agreement is not proof of correctness (both
models can be wrong the same way), so we bound the solver's reliability by
running it on a calibration set of questions with \emph{known} answers and
reporting its gold accuracy; the independent-match figures are interpreted
relative to that bound.

\subsection{Metrics}
\label{sec:eval-metrics}

For each pipeline $X$ and difficulty $d$, let $Q=\{q_1,\dots,q_N\}$ be its
questions, judged independently by judge $J$ with
$J(q)=(\text{correctness},\text{clarity},\text{difficulty\_match},
\text{distractor\_quality},\text{overall},\text{accept})$, numeric fields in
$[1,5]$, $\text{accept}\in\{0,1\}$. We report three metric families:

\paragraph{Judge metrics.} Mean scores per dimension and the accept rate
$\mathrm{Acc}=\frac{1}{N}\sum_i \text{accept}(q_i)$ (the fraction the judge
would put on a real exam).

\paragraph{Deterministic metrics.} The \emph{duplicate rate} flags
near-identical questions via string similarity with threshold $0.85$ (lower is
better --- the only such metric in our tables); structural validity is
enforced upstream by the generation gate, so it is $100\%$ by construction and
not tabulated.

\paragraph{Embedding metrics.} Using the sentence-embedding model that powers
retrieval, with lecture chunks $\{c_j\}$:
\begin{equation}
  \mathrm{Grounding} = \frac{1}{N}\sum_{i=1}^{N}\max_{j}\cos\!\big(\mathbf{e}(q_i),\mathbf{e}(c_j)\big),
\end{equation}
\begin{equation}
  \mathrm{Diversity} = 1 - \frac{1}{N}\sum_{i=1}^{N}\max_{k\neq i}\cos\!\big(\mathbf{e}(q_i),\mathbf{e}(q_k)\big).
\end{equation}

\paragraph{Validator--judge agreement (agentic only).} Treating the external
judge's \texttt{accept} as ground truth and the self-validator's \texttt{PASS}
as the prediction:
\begin{equation}
  P = \frac{TP}{TP+FP}, \quad
  R = \frac{TP}{TP+FN}, \quad
  F_1 = \frac{2PR}{P+R}.
\end{equation}
This measures whether the agent's own quality gate matches an external judge
(RQ3).

\subsection{Ranking}
\label{sec:eval-ranking}

A question that merely repeats an earlier one carries little exam value, yet a
judge scoring questions in isolation cannot see repetition. The primary
set-level ranking metric therefore discounts the accept rate by redundancy:
\begin{equation}
  \mathrm{Acc}_{\mathrm{eff}}(X) = \mathrm{Acc}(X)\,\big(1-\mathrm{DuplicateRate}(X)\big),
  \label{eq:acceff}
\end{equation}
so a set of distinct, accepted questions scores highest. We report
$\mathrm{Acc}$, $\mathrm{DuplicateRate}$ and $\mathrm{Acc}_{\mathrm{eff}}$
together so the effect of repetition on the ranking is transparent. For
per-dimension comparisons, saturated-judge ties are broken deterministically by
the content-quality margin
$T(X)=\mathrm{Grounding}(X)-\mathrm{DuplicateRate}(X)$.

\subsection{Pilot study (measured)}
\label{sec:eval-pilot}

plain non-agentic only, $N{=}10$ medium / $N{=}5$ hard). Table~\ref{tab:pilot}

the main evaluation, not to support the paper's claims.

The pilot produced three lessons that shaped the main evaluation:
\begin{enumerate}
  \item \textbf{Judge scores saturate.} At medium difficulty the judge
        assigned $5/5$ to nearly everything on both sides, separating nothing.
        This motivated the discriminating rubric, the duplicate-penalised
        ranking of Eq.~\eqref{eq:acceff}, and the deterministic tiebreaker.
  \item \textbf{Redundancy is the discriminator.} The baseline reached $5/5$
        at hard difficulty partly by asking near-identical questions
        ($80\%$ duplicates) --- invisible to a per-question judge, captured by
        the duplicate metric. Hence duplicate rate and diversity are retained
        alongside the EQGBench dimensions.
  \item \textbf{Small $N$ is inadequate.} $F_1$ and per-segment verdicts were
        unstable at $N\le 10$; the main run uses $N{=}50$ per cell and adds
        the CoT and PoT baselines.
\end{enumerate}

\paragraph{Limitations.} The judges are LLMs rather than human raters, so
absolute scores are a relative signal; the local judge shares the Gemma-3
family with the generator (mitigated by the cross-family DeepSeek judge and
inter-judge agreement, not eliminated); independent-match measures agreement,
not truth, and is bounded by the solver's measured gold accuracy; and all
results come from a single chapter of one subject, so cross-domain
generalisation is untested.
