\begin{column}{\colA}

  \begin{block}{Problem}

    \begin{itemize}
      \item Lecture knowledge is locked in \textbf{video, speech and board writing}.
      \item Generic quiz tools produce \textbf{ungrounded, off-topic} questions.
      \item Fixed difficulty ignores \textbf{each student's weak topics}.
    \end{itemize}

    \textbf{Goal.} Grounded, validated, adaptive study material --- fully local,
    \textbf{zero API cost}, on one free Colab T4.

  \end{block}

  \begin{block}{Evaluation Setup}

    \begin{itemize}
      \item \textbf{Source.} OpenStax \emph{Calculus Vol.\,1}, Limits chapter
        ($\approx$112k characters), also given to the judge as ground truth.
      \item \textbf{Scale.} $n{=}200$ MCQ per pipeline --- easy 68, medium 66,
        hard 66.
      \item \textbf{Fairness.} Identical sliding window for both pipelines, so
        any difference reflects \textbf{prompting strategy alone}.
      \item \textbf{Models.} Generator \texttt{gemma3:4b}, judge
        \texttt{gemma3:12b}, both local.
    \end{itemize}

  \end{block}

  \begin{block}{Stack}

    \begin{itemize}
      \item \textbf{Vision.} EasyOCR, per-surface preprocessing for slides,
        chalkboards and whiteboards.
      \item \textbf{Speech.} Faster-Whisper with per-segment timestamps.
      \item \textbf{Retrieval.} MiniLM embeddings in a FAISS cosine index.
      \item \textbf{Serving.} Flask on Colab $\rightarrow$ ngrok $\rightarrow$
        browser UI.
    \end{itemize}

  \end{block}

\end{column}

  \begin{block}{Conclusion}

    A fully local, \$0-API multimodal pipeline that turns a lecture into
    grounded, validated study material. The judged dimensions \textbf{saturate}
    ($4.36$--$5.00$), so only the automated metrics discriminate --- and on
    those the agentic loop does \textbf{not} beat single-pass prompting. The
    engineering contribution stands; the scientific claim is
    \textbf{not established}, and we report it that way.

  \end{block}
